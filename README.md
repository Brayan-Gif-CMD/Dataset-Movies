# Dataset-Movies
Este repositorio contiene un catálogo de películas que proporciona una lista organizada de títulos cinematográficos, incluyendo detalles clave como el nombre de la película, año de lanzamiento, género, sinopsis y duración. Cada entrada en el catálogo está diseñada para ofrecer información detallada y fácilmente accesible, permitiendo a los usuarios buscar y explorar películas según sus preferencias. Este repositorio también incluye funcionalidades de filtrado, clasificación por año o género, y una API para integrarse con aplicaciones de terceros que necesiten acceder a la información del catálogo.
